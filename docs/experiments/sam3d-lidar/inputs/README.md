# Example inputs

For each building (`b6`, the house; `b3`, the building behind trees), made from the training points only (see the experiment's "Held-out truth"):

- `oblique.png`: the virtual oblique photo (LINZ's aerial draped on the training-points DSM, seen at 45° in Blender). Synthetic: roofs look right, walls are smeared.
- `mask_overlay.png`: the building's mask (red) over it.
- `depth_lidar_moge_err.png` and `moge_check.json`: MoGe's depth against the LiDAR pointmap.

LINZ open data only (aerial photos and LiDAR, CC BY 4.0).
